Want to turn sales data into business dashboards? Let's chart it! 📊

For Day 16 of my 30-day R learning journey, I focused on advanced business graphics in ggplot2. I built a Sales Dashboard Charting script.

Using simulated transactional data, I built three publication-ready visualizations:
- A Stacked Bar Chart showcasing categorical sales split by region
- A Faceted Grid using facet_wrap() to break down monthly sales performance by category
- A Sales Heatmap using geom_tile() with custom color gradients to highlight regional sales intensity

Here is what I learned today:
- Splitting plots into sub-grids using facet_wrap()
- Building multi-category stacked bar charts
- Creating heatmaps using geom_tile() and scale_fill_gradient()
- Overlaying text labels on heatmap cells using geom_text()

Faceting in ggplot2 allows you to generate multi-panel charts with a single line of code.
