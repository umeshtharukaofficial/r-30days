Tired of manual math? Let's build a toolkit! 🧮

For Day 4 of my 30-day R learning journey, I structured a reusable Unit Converter Toolkit to master function definitions, default parameters, and scoping in R.

I coded five essential converters:
1. Celsius to Fahrenheit
2. Kilometers to Miles
3. Kilograms to Pounds
4. LKR to USD (with default exchange rates)
5. Body Mass Index (BMI) with safety validation

Here is what I learned today:
- Defining functions using R's function() syntax
- Designing flexible APIs with default argument values
- Understanding the difference between local and global scopes
- Error handling in R functions using stop() to protect input boundaries

A common pitfall for R beginners is lexical scoping and mutating variables outside functions. Writing pure functions with explicit inputs and outputs makes code significantly more predictable and testable.
