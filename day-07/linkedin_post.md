Where is your money going? Let's track it! 💸

For Day 7 of my 30-day R learning journey, I designed and coded a CLI-based Personal Expense Tracker. This project brings together everything I learned from Days 1 to 6 into a single, cohesive terminal application.

The tool manages financial entries through a flat CSV file database and provides key analytics:
- Reading and writing transactions to persistent storage
- Safely appending new records with formatted timestamp vectors
- Categorizing expenditures using the aggregate() function
- Slicing and displaying top-3 highest transactions with descending order indices

Here is what I learned today:
- Writing idempotent database files that auto-create columns on start
- Resolving type mutation issues during CSV serialization
- Grouping table metrics with aggregate(Formula, data, FUN)
- Slicing top items from ordered arrays

Building this CLI tool showed me how quickly you can create useful utilities in R without external databases.
