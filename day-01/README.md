# Day 01 — Personal Bio Calculator

**What I built:** A script that calculates BMI and outputs a formatted biography report based on raw user metrics.

**What broke:** `Error: object 'category' not found` because the `if/else` conditional logic block was skipped before running the message compiler.

**What I learned:** Basic R variable assignment (`<-`), casting types with `as.integer()`, and string concatenation using `paste0()` and `cat()`.

**Run it:**
Rscript bio_calculator.R
