Ready to move beyond basic R plotting? Let's build some gorgeous charts! 🌸

For Day 15 of my 30-day R learning journey, I dove into the grammar of graphics using the ggplot2 package. I built an Iris Explorer dashboard.

I generated four publication-quality visualizations from the classic iris dataset:
- A Scatter Plot mapping Petal Length vs Width, colored by Species
- A Histogram displaying Sepal Length distributions with a mean reference line
- A Bar Chart confirming class counts
- A Boxplot comparing Sepal Width variances across categories

Here is what I learned today:
- Defining chart grids and color mappings with aes()
- Layering chart types with geom_point(), geom_histogram(), and geom_boxplot()
- Adding details like custom labels, subtitles, and clean minimalism with theme_minimal()
- Exporting plots to high-quality png formats with ggsave()

Using ggplot2 completely changes how you think about plotting. The layered grammar lets you build complex charts step-by-step.
